# AI Fitness Test App

## Overview
The AI Fitness Test App is a mobile fitness application designed to help users improve their health by providing personalized workout recommendations, tracking progress, and evaluating fitness performance. The application integrates a workout API to deliver real exercise data and uses intelligent logic to recommend workouts based on the user's fitness level and goals.

## Key Features

- User registration and profile management
- Workout recommendations using external API
- Fitness level assessment through AI Fitness Test
- Browse exercises by category and difficulty
- Track fitness progress and workout history
- Clean, modern, and user-friendly interface
- Scalable architecture for future AI integration

## User Stories

- As a user, I want to browse workouts so I can find exercises that match my goals.
- As a user, I want personalized workout recommendations so I can improve efficiently.
- As a user, I want to track my progress so I can monitor my fitness improvements.
- As a user, I want to complete a fitness test so I know my current fitness level.
- As a user, I want an easy-to-use interface so I can navigate the app without confusion.

## Project Architecture

The application follows a modular architecture consisting of:

- User Interface Layer – Handles user interaction
- Application Logic Layer – Processes fitness tests and workout recommendations
- API Integration Layer – Retrieves workout data from external sources
- Data Layer – Stores user information and fitness progress
