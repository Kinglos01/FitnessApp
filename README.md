AI Fitness Test App
Overview
The AI Fitness Test App is a mobile fitness application designed to help users discover workouts, track their fitness progress, and improve their overall health. The application uses a workout API and intelligent features to provide personalized workout recommendations based on user goals, fitness level, and performance.
This project is being developed as part of a Computer Science group project. The application focuses on improving user fitness experiences through structured workouts, progress tracking, and modern mobile application development practices.

Project Goals
The main goals of the AI Fitness Test App are:
Provide users with workout recommendations
Allow users to track fitness progress
Help users improve strength, endurance, and overall fitness
Provide a clean and easy-to-use mobile interface
Integrate a workout API to retrieve real workout data
Use modern programming tools and development practices
Features
Current and planned features include:
User registration and login
Workout recommendations using API
Ability to browse workouts
Fitness test to evaluate user level
Progress tracking
User profile and fitness history
Simple and user-friendly interface
User Stories
Examples of user stories for the app include:
As a user, I want to browse workouts so I can choose exercises that match my goals.
As a user, I want to track my progress so I can see my improvement over time.
As a user, I want personalized workout recommendations so I can train effectively.
As a user, I want to view my fitness level so I know where to improve.
As a user, I want a simple interface so I can easily navigate the app.
